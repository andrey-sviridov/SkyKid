# Локализация SkyKid

## Поддерживаемые локали

| Код | Язык |
|---|---|
| `ru` | русский, исходный язык |
| `kk` | казахский |
| `en` | английский |
| `fr` | французский |
| `zh-Hans` | китайский, упрощённое письмо |

Каталоги основного приложения находятся в `SkyKid/Resources/<locale>.lproj`. Каталоги виджета находятся в `SkyKidWidget/<locale>.lproj`. Оба таргета должны содержать одинаковый набор ключей.

## Архитектура

- Русская пользовательская фраза является стабильным localization key.
- Статические подписи SwiftUI локализуются стандартным механизмом `LocalizedStringKey`.
- Динамические строки моделей, сервисов и форматируемые значения проходят через `Core/Localization/L10n.swift`.
- `L10n.text` возвращает готовую фразу, а `L10n.format` форматирует её с текущей локалью.
- `Core/Localization/AppLanguage.swift` хранит выбор пользователя в App Group и предоставляет один язык приложению и виджету.
- Переключатель находится в `Профиль → Язык приложения`; выбранная локаль применяется сразу, без перезапуска.
- Вариант «Как в системе» возвращает стандартный выбор языка iOS.
- Пользовательские тексты нельзя собирать из переведённых отдельных слов или русских окончаний.

## Генерация и проверка

`scripts/generate_localizations.py`:

1. экспортирует найденные Xcode ключи;
2. добавляет явные ключи `L10n`;
3. создаёт одинаковые каталоги приложения и виджета;
4. проверяет пустые значения и сохранность `%@`, `%lld`, `%d`, `%.1f`, `%%`;
5. применяет вручную отредактированные варианты ключевых родительских и safety-текстов.

Локальные модели являются только способом получить черновик. Они не входят в приложение и не запускаются на устройстве пользователя.

Базовые проверки:

```bash
python3 scripts/generate_localizations.py --validate-only

find SkyKid/Resources SkyKidWidget -path '*.lproj/*.strings' -print0 \
  | xargs -0 -n1 plutil -lint

xcodebuild -project SkyKid.xcodeproj -scheme SkyKid \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build

xcodebuild -project SkyKid.xcodeproj -scheme SkyKid \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

## Статус качества

На 24 июля 2026 года все пять каталогов технически полны: по 835 ключей в приложении и виджете. Ключевые тексты карточки одежды, проверки комфорта, лихорадки, дождевика и автокресла отредактированы вручную после локального машинного черновика.

Это не заменяет профессиональную языковую редактуру. До релиза нужны:

1. вычитка носителем каждого целевого языка;
2. отдельная проверка терминов одежды и естественности коротких UI-подписей;
3. клиническое согласование всех переведённых медицинских и safety-текстов;
4. визуальная проверка онбординга, профиля, погоды, одежды, гардероба, истории и виджета;
5. проверка VoiceOver и Accessibility Dynamic Type для каждой локали.

Перевод нельзя считать клинически согласованным только потому, что русский исходный текст получил sign-off. Решение по каждой языковой версии должно быть зафиксировано отдельно.
